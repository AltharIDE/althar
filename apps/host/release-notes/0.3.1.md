Althar 0.3.1 for Linux lets a home ask its workers to update now.

- A home can ask its workers to update, from **Settings › Computers** or the window's Updates icon. A worker updates between tasks, or once it connects, and says how it went. The icon gathers every update: Althar's, the home's and the workers'.
- A worker on 0.3.0 can't be asked yet. It moves to 0.3.1 on its own hourly timer, while it runs no task, and from then on its home can ask it.
- A home's window now has the status line: run the project and open terminals in its folders on the home.
- A model that drops off an agent's list for a while no longer stops a task at once. Althar asks again for six minutes, then tries the same model on another agent, and only then asks you.
- Fixed a timing fault where a pull request's conflict could be recorded wrongly until the next look at it.

Update from the window: Settings in a home’s window offers it, or run this on the home:

```sh
sh "${XDG_DATA_HOME:-$HOME/.local/share}/althar-host-program/launcher" update --apply --wait
```

Some of these also need a desktop app new enough to have them.

A home and its agents run as one OS user and share that user's file access. Use a dedicated account and code you trust.
