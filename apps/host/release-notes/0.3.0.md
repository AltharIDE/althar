Althar 0.3.0 for Linux lets workers clean up after themselves and update on their own.

- Workers clean up each run's checkout and scratch once the home has recorded how it ended. Removing a worker in **Settings › Computers** uninstalls it, at once or when it next reaches its home.
- Workers now have a smaller release of their own. A new one installs it. One already set up takes two updates to get there: its first installs the 0.3.0 home release as before, and the next, an hour or so later, moves it to the worker release.
- A task waits for a worker that another task is using, and says which, instead of failing.
- A lead lost in the middle of a turn after its plan carries on by itself, once. A message that no lead is on its way to read says Not sent, with Send again.
- Ask the coordinator or a lead to put a task on a particular worker, before it starts or while it's under way. Where that worker can't be used, the answer says why.
- Tell a task's lead to merge its pull request or tag a release, and it does so on your word.
- Sign in to GitHub or GitLab from the window with a code you approve in any browser.
- While Claude Code or Codex still has an imported conversation open, Althar doesn't send your message and puts it back in the composer. Close the conversation there, then send again.
- Anything Althar can't watch for is now refused with the reason, instead of staying on hold.
- Newer Claude and Codex adapters.

Update from the window: Settings in a home’s window offers it, or run this on the home:

```sh
sh "${XDG_DATA_HOME:-$HOME/.local/share}/althar-host-program/launcher" update --apply --wait
```

Some of these also need a desktop app new enough to have them.

A home and its agents run as one OS user and share that user's file access. Use a dedicated account and code you trust.
