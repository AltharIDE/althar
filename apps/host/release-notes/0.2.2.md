Althar 0.2.2 for Linux lets a window change its home's settings.

- Change the home's own settings from the window: how its tasks go, pull requests, presets, agents at once, automations, how long finished tasks' folders are kept, MCP servers and skills. Settings shows them under the home's name, apart from this computer's. Project rules aren't changed there, and trusting outside code fully, removing task folders and removing your own presets stay with the person on the home.
- See the pictures a home's threads show, such as a lead's screenshots, in the window.
- A code host token that can't push to a project's repository says so when connected and on the project's card. A refused push that would open a pull request says whose sign-in and which repository, and what puts it right.
- Clone several repositories into a new project at once. The list says when a GitHub token or Althar's app may reach only some repositories, and includes archived ones.
- While pull requests are on their way into a branch, the thread shows them in one line at its foot.
- In a fork whose work goes upstream, the coordinator finds and merges its pull requests there.

Update from the window: Settings in a home’s window offers it, or run this on the home:

```sh
sh "${XDG_DATA_HOME:-$HOME/.local/share}/althar-host-program/launcher" update --apply --wait
```

The new screens in the window also need a desktop app new enough to have them.

A home and its agents run as one OS user and share that user's file access. Use a dedicated account and code you trust.
