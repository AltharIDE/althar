Althar 0.2.1 for Linux lets a window set its home up.

- Sign a home's agents in from the window: Claude Code's page opens in your browser and you paste its code back; Codex signs in with a one-time code. Each sign-in stays on the home.
- Connect GitHub, GitLab or Bitbucket on a home from the window, with a token made on the host's page or the home's own `gh` or `glab` sign-in. Its repositories are then offered to clone there, private ones included.

Update from the window: a home's welcome offers it, or run this on the home:

```sh
sh "${XDG_DATA_HOME:-$HOME/.local/share}/althar-host-program/launcher" update --apply --wait
```

Signing in and connecting from the window also need a desktop app new enough to have them.

A home and its agents run as one OS user and share that user's file access. Use a dedicated account and code you trust.
