Althar's first standalone Linux host keeps a personal project home running independently of its clients.

- Persistent identity and SQLite data, separate-key encrypted connector credentials, private API health and systemd user-service supervision.
- Portable Linux x64 and arm64 releases include Node and the locked provider adapter/native CLI dependencies.
- Signed updates download and verify in the background. Applying is explicit by default; compatible updates can optionally apply on the next service start.

This release is a trusted personal OS-user boundary. SSH bootstrap, protected remote client enrollment, remote files/previews and isolated workers remain separate work. Real VPS reboot and provider headless login/refresh validation must be completed before publishing this draft.
