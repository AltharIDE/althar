# The new-project lab

Setting up a project in a folder with no remote, on the kit's own `NewProject`, `ProjectRepositories` and `ChangeSet`, with no runtime.

```bash
cd apps/desktop && ../../node_modules/.bin/vp dev --config lab/new-project/vite.config.ts
```

At `http://localhost:6163`. Its name and folders come first, on the page as it is, each folder read for what it is; Continue then walks where its work goes as Althar's own walks into GitHub, GitLab and Linear do, one card at a time in the side's place: where its code lives, its new repository on the host (owner, name, who sees it), where its issues go, a Linear team, then Create, its lines ticking as it's made. Keys A–C swap the direction (today; a card a question; ready in one press, the last card first with what was chosen before), 1–8 the folder (empty, files without git, git without commits, git without a remote, one that can't be read, one that's a project already, the project at work, a remote added), G what is connected (GitHub, GitLab and Linear; GitHub only; nothing), T the theme; Escape goes back a card. The line under the bars says what that folder does in Althar today. `?d=b&s=files&c=all&card=host&theme=dark` opens on one card (`code`, `host`, `issues`, `team`, `ready`).

`node lab/new-project/shoot.ts` shoots each at 1× into `lab/new-project/shots`, with the lab running (outside an agent's sandbox on a Mac).
