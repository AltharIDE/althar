What changed since 0.1.0.

- A finished task ends with what it built, the evidence its lead showed (screenshots, test runs and what they printed) and anything it couldn't check. The same summary leads its pull request, and the reviewer reads the evidence too.
- Set how many agents run at once on this Mac in Settings. Past that, tasks wait for a free place; a dev server sitting idle doesn't take one.
- Rename a task from its header or its menu.
- Code in messages has a Copy button.
- A long dictation scrolls in the composer instead of growing it.
- On Linear and Jira, a task's issue moves to In Progress when the task starts.
- The coordinator hands over to a fresh session before its context fills, so a long-running project keeps its thread.
- A task whose branch drifted from its pull request offers to bring the two together, instead of failing the push.
- Fixed: Push sends every commit and the count clears; the Settled column shows its real total; a conflict round no longer fails while the lead is still working; the thread keeps following new messages after a task finishes.
- Althar's app can no longer be started as a plain Node runtime.

Tell us what breaks: https://github.com/AltharIDE/althar/issues
