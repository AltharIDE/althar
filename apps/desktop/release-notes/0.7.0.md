What changed since 0.6.1.

Reviews, supercharged: a review's findings sit at their lines, and the pull requests Althar opens show who reviewed them and what changed. Each task shows what it used of your plans, tasks can work in your own checkout, and the coordinator merges, queues and releases on your word.

## New

- **Review findings in the Changes view.** A review's findings show at the lines they're about, with what the lead did about each. [ and ] move between them.
- **Review section and seal on pull requests.** The pull requests Althar opens say who reviewed them, in how many passes, and what changed after review.
- **Screenshots on pull requests.** A task's screenshots go on its pull request in one comment, kept up to date.
- **Welcome and setup on first launch.** A short tour, then signing in your agents, picking a project and connecting your code host and tracker.
- **Usage per task.** Each task shows how much of your plans, or how many dollars, its agents used.
- **Tasks in your own checkout.** A task can work Local, in your checkout, instead of a worktree of its own. Set the default in Project settings.
- **Mermaid diagrams** in threads and documents.
- **Coordinator merges, queues and releases.** Ask it to merge a pull request once it's green, bring a branch up to date, or tag and publish a release, and it does, using the host's merge queue where there is one.
- **Coordinator stops, holds, restarts and settles tasks** when you ask.
- **Intel Mac build,** beside the Apple silicon one.
- **Quit confirmation.** Quitting while work runs says what it will stop, and can keep working in the background.
- **Coordinator follows every open pull request** in the project, not only its tasks' own.
- **Task folder setup.** Althar learns how to set up a new task's folder once and repeats it for every task.
- **Web access for leads,** without asking. On by default.
- **New repository for a new project,** from the New project page.
- **Plans and reviews, and New projects, in Settings,** for countdowns, review rounds and new projects' rules.
- **Pushing to the original repository from a fork,** once you have access there.

## Improved

- **Conflicts and failed checks go to the lead automatically,** now on by default.
- **Fewer cards in Needs you:** only what needs a decision from you.
- **Stopped leads restart** on a comment or review on their pull request.
- **Issue moves apply at once** when issues move along with their tasks.
- **More tracker fields** for leads and the coordinator to set.
- **Run menu** that says where each run goes: the default branch, a task, or a pull request.
- **Fewer permission asks** for safe git, and an ask for what tears down or publishes.
- **Full CI logs for leads,** for any job.
- **Stuck steps hand on to any model.**
- **Syntax highlighting in diffs.**
- **Model browser and chips:** usable models first, plainer names.
- **Question cards** read as one line.
- **OpenCode Go in Plan usage.**
- **Four more project colours.**
- Copilot reaches GitHub Enterprise Cloud tenants named by `GH_HOST`.
- Claude Code's adapter is 0.100.0 and Codex's is 2.5.0.

## Fixed

- Restarting Althar twice no longer pauses the running step.
- A change task that built nothing no longer says "Ready to accept".
- A stopped task with a green pull request can still be merged.
- A conversation Claude Code lost starts afresh instead of failing with "Resource not found".
- OpenCode 2 sign-ins are recognised, and an older OpenCode no longer fails with a raw database error.
- Running on the default branch reinstalls when the lockfile changes.
- Changing a held task's plan keeps it held.
- A task in the merge queue no longer shows Review as still running.
- Jira Cloud on its own domain works.
- A project with a tracker bound by hand no longer says "No tracker yet".
- Agents' own memory files no longer show up as documents.
- On a Mac, leads can take screenshots of Electron apps again.

Tell us what breaks: Report a problem in the app, or https://github.com/AltharIDE/althar/issues
