What changed since 0.4.1.

## New

- Althar on Windows: an installer for x64 that installs for you alone, with no administrator's prompt, and updates itself. It isn't signed yet, so SmartScreen warns the first time: More info, then Run anyway.
- Seven more agents: GitHub Copilot, Junie, Grok Build, Kimi Code, Mistral Vibe, Qwen Code and Google Antigravity. Each one joins only where Althar can keep it asking before it acts. Althar can download Copilot and Antigravity for you; for the others, the first screen and Settings open the maker's page on installing it.
- Attach a task to a pull request it didn't open, by its link or number, from the task's menu. The task then follows it as its own: reviews, comments, checks and conflicts reach it, and pushing adds to that pull request instead of opening a second.
- A task's lead can draft issues on your trackers. Each draft is a card in the task's thread, to file, edit or throw away, and the task waits in Needs you until you have.
- Up next lists every task waiting for a free agent, whatever its kind, with its place in line. Drag a row to change the order, or use the menu on its grip.
- Drag a project's tab along the bar to reorder your open projects. ⌥⇧← and ⌥⇧→ move the focused tab.
- A project's settings are a page of the project, beside its board: General, Code and issues, Rules, Running and Notes. Notes can be edited, and show their formatting instead of its marks.

## Improved

- A finished quick task, prototype or review waits in Needs you until you choose Done or Keep for later, instead of settling itself the moment you open it. Kept tasks are under Kept for later, beside Settled.
- When an agent runs out of usage, the card and the thread say which agent, on which step, until when, and what Althar is doing about it. You can pick another model for the stopped step at any time, not only when the project is set to ask.
- A task's Outputs page is two columns: what the task is and its pictures as it is now on the left, the change on the right, with its checks, its review, the one action that fits, and its files by folder.
- When the board is too narrow for its four lanes, they fold to slim rails instead of running off the side. Needs you stays open while anything waits in it, and any lane folds by hand from its header.
- A project's views read Home, Conversation, Board, Settings. Home, the board beside the conversation, was called Both and comes first now.
- Task cards in the coordinator's chat are tidier: status, what is happening now and when it started on top, and one row underneath at any width.
- Project settings are calmer: fewer words, titles that read as titles, and commands and paths shown as code.
- Hover, press and focus look the same across the app, and the window buttons drawn off a Mac show their glyphs.
- When you dictate a message, the agent is told, so a misheard name ("Alpha" for Althar) is read generously.

## Fixed

- A redirect before a command, as in `> /dev/null git push --force`, no longer gets it past asking: it asks, or is refused, as the same command does without one.
- After a long shutdown, a task whose lead was working carries on by itself, instead of going stuck seconds after the next launch.
- A failed check's log on GitHub can be read again: the card shows it and the lead gets it, instead of "The code host said: 401".
- Opening Althar a second time, or while the command line has the same profile open, says another copy is using it, instead of restarting again and again and reporting a crash.
- On Linux without a keyring, Althar says how to install one, instead of the general keychain message.
- In a Linux Flatpak, sign-ins are kept across restarts. One made before 0.5.0 may need making once more.
- A pull request or conflict Althar can't read no longer stops it reading the rest.
- When a step's agent can't start, the step says why, instead of "SessionFailed:.".
- A queued message's preview stays inside the composer: three lines at most, and long links break.
- An event with no text, like "Checks passed", no longer draws an empty box under its line.

Tell us what breaks: Report a problem in the app, or https://github.com/AltharIDE/althar/issues
