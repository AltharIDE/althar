# Handoff

A prototype for "Althar for the whole team" (`docs/plans/whole-team.md`, ADR-108 to ADR-111): the flows before Build, as stories on made-up data (`data.ts`). Saved carts goes from its spec being written to its design going into a pull request.

1. **Choosing roles:** the first-run "What do you do in storefront?" (several roles, per project), and the lens chip's menu later. Nothing is hidden by a role.
2. **Writing a spec:** product's view of `specs/saved-carts/spec.md`, its frontmatter as the head, drafted by the coordinator from SHOP-212, then its pull request as Spec's artefact.
3. **The handoff:** the spec merges, design's inbox has it, and their coordinator's proposed tasks wait, held, until accepted.
4. **Asking back:** design asks product a question; the stage doesn't move.
5. **The feature page:** stages, artefacts, pull requests, the code host's gates (read only, ADR-111), and who it waits on.
6. **Design's lens:** canvases and screenshot diffs beside the feature, and `design/` going into a pull request.

Light and dark from the toolbar. `shoot.mjs` shoots every story in both. A prototype: nothing in the kit uses it.
